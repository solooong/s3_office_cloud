# 10. Руководство пользователя

Это инструкция для сотрудников. Технических знаний не требуется — достаточно
браузера и учётной записи, выданной ИТ-отделом. Адрес сервиса в вашей организации
указан в письме-приглашении; в примерах используется `https://cloud.example.com`.

## 1. Вход в систему

1. Откройте в браузере `https://cloud.example.com`.
2. Введите логин (обычно `фамилия` или `имя.фамилия`) и пароль.
3. Если включена двухфакторная защита, введите шестизначный код из приложения
   аутентификации (Google Authenticator, Aegis, 1Password и т. п.).
4. Нажмите **«Войти»**.

Возможные сообщения:

| Сообщение | Что делать |
|---|---|
| «Неверный логин или пароль» | проверьте раскладку и Caps Lock; после 5 ошибок вход блокируется на несколько минут |
| «Слишком много попыток входа» | подождите 15–30 минут или обратитесь в ИТ |
| «Введите код двухфакторной аутентификации» | откройте приложение с кодами, код действует 30 секунд |
| «Ваша учётная запись отключена» | обратитесь в ИТ-отдел |

Если пароль забыт — ссылка **«Забыли пароль?»** на странице входа (работает, если
в организации настроена почта). Иначе пароль меняет администратор.

**Смените пароль при первом входе:** меню пользователя (кружок в правом верхнем
углу) → **«Настройки»** → **«Безопасность»** → **«Изменить пароль»**.

## 2. Что где находится

| Раздел | Что там |
|---|---|
| **Файлы** | ваши папки и файлы, загрузка, поиск |
| **Недавние** | последние открытые и изменённые файлы |
| **Избранное** | файлы, помеченные звездой |
| **Общие ресурсы** | то, чем с вами поделились коллеги |
| **Удалённые файлы** | корзина, хранение 30 дней |
| **Фотографии** | галерея изображений |
| Кружок в правом верхнем углу | настройки, пароли приложений, выход |

В левом нижнем углу показано, сколько места занято: например,
«2,4 ГБ из 20 ГБ».

## 3. Установка приложения на компьютер

### Windows и macOS

1. Скачайте клиент: `https://cloud.example.com/settings/user` → раздел
   **«Мобильные и настольные клиенты»**, либо с `https://nextcloud.com/install/`.
2. Запустите установщик и укажите адрес сервера:
   `https://cloud.example.com` (без слэша в конце).
3. Нажмите **«Войти»** — откроется браузер, где нужно подтвердить вход и разрешить
   доступ приложению. Это безопаснее, чем вводить пароль в самом клиенте.
4. Выберите папки для синхронизации и нажмите **«Подключиться»**.

С этого момента файлы в выбранной папке синхронизируются автоматически. Значок в
системном трее показывает состояние: зелёный — всё синхронизировано, синий —
идёт синхронизация, красный — ошибка (наведите курсор, чтобы увидеть причину).

### Linux

**Вариант 1 — AppImage (универсально):**

```bash
chmod +x Nextcloud-*.AppImage
./Nextcloud-*.AppImage
```

**Вариант 2 — пакет дистрибутива:**

```bash
# Debian / Ubuntu
sudo apt install nextcloud-client

# Fedora
sudo dnf install nextcloud-client

# Arch
sudo pacman -S nextcloud-client
```

Далее — как в Windows/macOS: адрес `https://cloud.example.com`, вход через браузер.

### Мобильные устройства

* **Android:** Google Play / RuStore → «Nextcloud».
* **iOS/iPadOS:** App Store → «Nextcloud».

При первом запуске нажмите **«Войти»**, введите адрес
`https://cloud.example.com` и пройдите вход. Включите автозагрузку
фотографий, если это разрешено политикой организации.

### WebDAV (без установки клиента)

Файлы можно подключить как сетевой диск:

| Параметр | Значение |
|---|---|
| Адрес | `https://cloud.example.com/remote.php/dav/files/<ваш-логин>/` |
| Пользователь | ваш логин |
| Пароль | **пароль приложения** (см. п. 11), а не основной пароль |

Windows: «Этот компьютер» → «Подключить сетевой диск» → ввести адрес.
macOS: Finder → «Перейти» → «Подключиться к серверу» (⌘K).
Linux (GNOME/KDE): «Подключиться к серверу» → тип «WebDAV (HTTPS)».

## 4. Загрузка и скачивание

* **Загрузить файл:** кнопка **«+»** в верхней панели → **«Загрузить файл»**, либо
  просто перетащите файлы в окно браузера.
* **Создать папку:** **«+»** → **«Новая папка»**.
* **Скачать:** наведите курсор на файл → значок **«…»** → **«Скачать»**.
  Для папки скачивается ZIP-архив.
* **Переименовать/переместить:** **«…»** → **«Переименовать»** или
  **«Переместить или скопировать»**.
* **Поиск:** строка поиска вверху; ищет по имени файла и по содержимому
  документов (если включён полнотекстовый поиск).

Ограничения: максимальный размер одного файла — до 10 ГБ (значение задаёт
администратор), общий объём — ваша квота. При превышении квоты загрузка
отклоняется с сообщением «Недостаточно места».

## 5. Общий доступ для коллег

1. Наведите курсор на файл или папку → значок **«Поделиться»** (человечек с «+»).
2. В поле **«Поделиться с пользователями или группами»** начните вводить фамилию
   или название отдела — выберите нужного человека или группу.
3. Выберите права:

| Право | Что разрешает |
|---|---|
| «Просмотр» | открывать и скачивать |
| «Редактирование» | изменять, переименовывать, создавать внутри папки |
| «Поделиться» | передавать доступ дальше (обычно отключено политикой) |
| «Удаление» | удалять файлы в общей папке |

4. Нажмите **«Отправить»** — коллега увидит папку в разделе **«Общие ресурсы»**
   и получит уведомление на почту (если настроено).

Отозвать доступ: тот же значок → у нужного человека **«…»** → **«Удалить общий
ресурс»**.

Важно: если папка расшарена группе, доступ получают все её участники, включая
новых сотрудников. Для персонального доступа делитесь с конкретным человеком.

## 6. Публичные ссылки

Публичная ссылка позволяет открыть файл без входа в систему — например, чтобы
отправить документ подрядчику.

1. Значок **«Поделиться»** → блок **«Поделиться ссылкой»** → **«+»**.
2. Настройте:

| Настройка | Смысл |
|---|---|
| **Права** | «Только просмотр» — скачать/посмотреть; «Разрешить редактирование» — изменения вносятся от вашего имени |
| **Пароль** | обязателен по политике организации; передавайте пароль отдельным сообщением (SMS/звонок), не в той же почте |
| **Срок действия** | дата, после которой ссылка перестаёт работать (по умолчанию 30 дней) |
| **Заметка** | внутренний комментарий, виден только вам |

3. Скопируйте ссылку и отправьте адресату.

Правила безопасности:

* ссылка = пароль от файла, не публикуйте её в открытых чатах и на сайтах;
* для «с редактированием» включайте срок действия — так вы ограничите окно риска;
* при увольнении сотрудника или подозрении на утечку администратор может удалить
  все публичные ссылки.
* любая публичная ссылка видна в аудит-логе: создание, скачивание, правки
  фиксируются.

## 7. Офисные документы в браузере

Поддерживаются DOCX, XLSX, PPTX, ODT, ODS, ODP, PDF (просмотр).

1. Откройте файл двойным щелчком — он откроется в редакторе прямо в браузере.
2. Изменения сохраняются автоматически (в строке состояния — «Все изменения
   сохранены»).
3. Совместная работа: если файл одновременно открыли несколько человек, их курсоры
   видны разными цветами. Кнопка **«Соавторы»** показывает, кто сейчас в документе.
4. Закрытие вкладки без сохранения — изменения уже сохранены автоматически, но
   нажмите **Ctrl+S** (⌘S) перед закрытием, если строка состояния показывает
   сохранение.

Скачивать и редактировать локально тоже можно: **«…»** → **«Скачать»** →
измените в Word/Excel → загрузите обратно (создастся новая версия).

Если редактор не открылся: обновите страницу, проверьте, что открыт доступ к
`https://office.example.com` (корпоративный прокси иногда его блокирует),
и обратитесь в ИТ, если ошибка повторяется.

## 8. Версии файла и восстановление

Nextcloud хранит до **20 предыдущих версий** каждого файла (точное число задаёт
администратор).

1. Откройте панель сведений: значок **«i»** справа или **«…»** → **«Сведения»**.
2. Перейдите на вкладку **«Версии»**.
3. Выберите нужную версию — она откроется для просмотра.
4. **«Восстановить»** — версия станет текущей (текущая сохранится как ещё одна
   версия, ничего не потеряется). **«Скачать»** — забрать копию, не меняя файл.

Версии хранятся 30 дней, затем удаляются автоматически. Если файл изменялся очень
часто, сохраняются не все промежуточные варианты, а последние 20.

## 9. Корзина

* Удалённые файлы попадают в **«Удалённые файлы»** и хранятся **30 дней**.
* **«Восстановить»** — вернуть файл на прежнее место.
* **«Удалить навсегда»** — удалить немедленно (восстановление невозможно).
* Корзина занимает место в вашей квоте. Чистите её, если место заканчивается.

Через 30 дней файлы удаляются автоматически, без возможности восстановления.

## 10. Квоты

Квота зависит от роли:

| Роль | Квота |
|---|---|
| Сотрудник | 100 ГБ |
| Руководитель подразделения | 500 ГБ |
| Внешний подрядчик | 20 ГБ |
| Аудитор / ИБ | 5 ГБ |
| Без назначенной роли | 10 ГБ |

Точные значения — в `config/rbac/roles.yaml` вашей организации. Посмотреть
занятое место: левый нижний угол в «Файлах» или **«Настройки»** → **«Личное»**.

Если места не хватает:

1. очистите корзину;
2. удалите неиспользуемые большие файлы (их версии удалятся автоматически);
3. запросите расширение квоты у руководителя/ИТ.

## 11. Безопасность учётной записи

### Двухфакторная аутентификация (2FA)

**«Настройки»** → **«Безопасность»** → **«Двухфакторная аутентификация»** →
**«Включить TOTP»**:

1. установите приложение-аутентификатор на телефон;
2. отсканируйте QR-код;
3. введите шестизначный код для подтверждения;
4. сохраните резервные коды в надёжном месте — они нужны, если телефон потерян.

Если 2FA включена администратором принудительно, без неё вход невозможен.

### Пароли приложений

Для десктоп-клиентов, мобильных приложений и WebDAV используйте отдельные пароли:

**«Настройки»** → **«Безопасность»** → **«Пароли приложений»** → введите название
(например, «Ноутбук») → **«Создать»**. Пароль показывается один раз — скопируйте
его в клиент. Отозвать: там же, кнопка **«Отозвать»**.

Так основной пароль не хранится в клиентах и его можно сменить, не перенастраивая
устройства.

### Правила

* не передавайте пароль коллегам — делитесь файлами, а не учётной записью;
* не сохраняйте пароль в браузере на общих компьютерах;
* выходя с чужого компьютера, нажимайте **«Выйти»** и закрывайте браузер;
* при подозрении на взлом сразу смените пароль и сообщите в ИТ.

## 12. Частые вопросы

**Где мои файлы физически?** На сервере вашей организации, объектное хранилище S3.
Данные не передаются в Яндекс и другие облака.

**Можно ли работать без интернета?** Десктоп-клиент хранит локальную копию
синхронизированных папок — открывать файлы можно, изменения синхронизируются при
появлении сети. Веб-интерфейс без сети не работает.

**Почему файл не загружается?** Чаще всего: превышена квота, размер больше 10 ГБ
или нестабильная сеть. Проверьте свободное место (левый нижний угол).

**Почему не открывается редактор?** Браузер должен иметь доступ к
`https://office.example.com`. Попробуйте другой браузер, отключите блокировщики
рекламы для домена, обратитесь в ИТ.

**Как отправить файл внешнему получателю?** Публичной ссылкой с паролем и сроком
действия (п. 6). Для постоянного сотрудничества запросите гостевую учётную запись.

**Что будет, если я удалю файл из общей папки?** Он попадёт в корзину владельца
папки. Восстановить может владелец или администратор.

**Кто видит мои файлы?** Только те, кому вы сами дали доступ, и администраторы
(в рамках администрирования). Все действия фиксируются в журнале аудита.

**Как перенести файлы с Яндекс.Диска?** Массовый перенос выполняет ИТ-отдел по
[08-migration-from-yandex-disk.md](08-migration-from-yandex-disk.md); самостоятельно
можно скачать нужные файлы на компьютер и загрузить в Nextcloud.

**Сколько хранятся удалённые файлы и версии?** 30 дней, затем удаляются
автоматически.

**Как поменять имя/фамилию в профиле?** **«Настройки»** → **«Личное»** — часть
полей может быть заблокирована администратором (данные из корпоративного каталога).

## 13. Куда обращаться

| Вопрос | Куда |
|---|---|
| Забыли пароль, отключена учётная запись | ИТ-отдел / helpdesk |
| Не хватает квоты | руководитель подразделения |
| Ошибка в работе сервиса | ИТ-отдел, приложите скриншот и время |
| Подозрение на утечку/взлом | ИТ-отдел и служба безопасности немедленно |

При обращении укажите: логин, время (с часовым поясом), что делали, текст ошибки,
браузер/клиент и версию.
